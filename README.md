# 📝 To-Do List

A simple and responsive **To-Do List Web Application** built using **HTML, CSS, and JavaScript**.

## 🌐 Live Demo

👉 [To-Do List Live Website](https://pradeepsarav2007-spec.github.io/todo-list/?utm_source=chatgpt.com)

## 📌 About the Project

This project is a basic task management application that allows users to add tasks, mark tasks as completed, and delete tasks.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📱 Responsive design
* 🎨 Simple and clean user interface
* ⚡ Fast and easy to use

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive design
* **JavaScript** – Task management and user interaction

## 📂 Project Structure

```text
todo-list/
│

```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/pradeepsarav2007-spec/todo-list.git
```

2. Open the project folder.

3. Open `index.html` in any web browser.

## 💻 How to Use

1. Enter a task in the input box.
2. Click the **Add** button.
3. Click a task to mark it as completed.
4. Click the **Delete** button to remove a task.

## 🎯 Project Objective

The objective of this project is to create a simple web-based task management application while learning the fundamentals of **HTML, CSS, JavaScript, DOM manipulation, and GitHub Pages deployment**.
